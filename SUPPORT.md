# Getting help

For setup, start with the [installation guide](docs/getting-started.md) and
[troubleshooting](docs/troubleshooting.md). For model compatibility, check the
[capability matrix](docs/capability-matrix.md) and the dashboard's Environment view.

If the problem remains, [open an issue](https://github.com/AlBrmagawi/modelport/issues/new/choose)
with your OS, installation method, ModelPort version, exact reproduction steps and
the structured error code. A small generated model or reproduction script is more
useful than a private production model.

Review logs before sharing them. Keep operator tokens, private model weights and
sensitive data out of public issues. Follow [SECURITY.md](SECURITY.md) for a
security vulnerability.

Feature requests should describe the workflow, model format, runtime and expected
result. Support is provided through the repository on a best-effort basis.
